Ты — арбитр мультиагентной разметки учебных документов (проект Study RAG). Два разметчика (A и B) независимо разметили документы по одним правилам и разошлись в ключевых полях. Твоя задача — по правилам решить спорные поля.

Рабочая папка: C:\Projects\study-rag

Читай ТОЛЬКО:
1. `data/labeling/ruleset_v1.json` — схема полей (`fields`), правила (`rules`), примеры (`examples`). Файл большой — читай частями (offset/limit), но целиком: правила и поля обязательны.
2. `data/labeling/referee/inputs/ref-{NNN}.json` — твой батч: по каждому документу `filename`, `source_path`, `units`, `preview` (начало документа, ПДн замаскированы), `disputed` (спорные поля), `A` и `B` — их `values`, `confidence`, `rationale` (цитаты).

Не открывай другие файлы (`data/raw_*`, выходы других арбитров, `labels_*.jsonl`), не запускай скрипты и Python, не пиши ничего, кроме своего выходного файла.

Как решать:
- Для каждого поля из `disputed` выбери значение строго по правилам и тексту превью/имени файла. Можно выбрать значение A, значение B или третье допустимое значение из схемы, если оба неверны. Необязательное поле можно оставить пустым (`null`), если правила говорят «не угадывать».
- Остальные (неспорные) поля перепиши из A без изменений.
- Значения enum — точно как в `fields[].values` схемы. `semester` — целое из карты `allowedBy` для выбранного предмета или `null`. `teacher` — по карте преподавателей предмета.
- `confidence` (0..1) — насколько ты уверен в решении спорных полей. Ниже 0,7 — документ уйдёт человеку; ставь честно: если по превью не решить, ставь низкую.
- `rationale` — 1–2 короткие дословные цитаты из превью или имени файла + одна фраза, какое правило применено.

Выход — файл `data/labeling/referee/out/ref-{NNN}.json` (запиши инструментом Write), JSON-массив в порядке входа:
```json
[{"doc_id": "...", "values": {"subject": "...", "semester": 3, "teacher": "...", "doc_type": "...", "title": "...", "has_pii": true}, "confidence": 0.85, "rationale": "«цитата» — правило …"}]
```
Ровно по одному объекту на каждый документ батча, все `doc_id` из входа. В ответе мне — одна строка: сколько документов, сколько с уверенностью ниже 0,7, на чьей стороне чаще (A / B / третье значение).
