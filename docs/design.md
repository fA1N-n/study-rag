# Дизайн — вариант A «Консоль»

Выбран 2026-11-07 из трёх вариантов (критерий пользователя: «все красивые, бери тот, что проще и быстрее сделать»). Моки — `docs/design/variant-{a,b,c}.html` (`?screen=chat|board&theme=light|dark`), скриншоты трёх итераций — `docs/screenshots/design/` (по 6 кадров: чат и доска × светлая, тёмная, 375 px). Пересъёмка: `bash docs/design/shot.sh <a|b|c> <chat|board> <light|dark|375>`.

| Вариант | Характер | Доска разметки | Почему не выбран |
|---|---|---|---|
| **A Консоль** | плотный, нейтральный, Inter + JetBrains Mono, радиус 6–10 px | KPI → полоса и сетка батчей → дорожки агентов → таблица решений | выбран: плоские карточки и таблицы, меньше всего кастомной вёрстки |
| B Конспект | мягкий, скруглённый, бирюзовый, Manrope; чат пузырями | канбан по статусу документа | канбан на 568 документах требует виртуализации колонок |
| C Пульт | контрастный, сетка без скруглений, Unbounded; ответ — пронумерованные утверждения | схема конвейера + журнал + график | своя сетка и две темы с разным акцентом — больше ручной работы |

## Токены (`src/app/globals.css`)

| Токен | Светлая | Тёмная | Где |
|---|---|---|---|
| `bg` | #f7f7f8 | #0b0b0d | фон страницы |
| `panel` | #fff | #131316 | карточки, колонки |
| `sub` | #f1f1f3 | #1b1b1f | подложки, пустые клетки |
| `ink` / `mute` | #18181b / #71717a | #ececf1 / #8b8b95 | текст / вторичный |
| `line` | #e4e4e7 | #27272c | рамки 1 px |
| `acc` / `acc-soft` | #4f46e5 / #eef2ff | #818cf8 / #1e1b4b | действия, сноски, «в работе» |
| `ok` / `warn` / `bad` | #16a34a / #d97706 / #dc2626 | #4ade80 / #fbbf24 / #f87171 | agreed / арбитр / ошибка, человеку |
| `hl` | #fef08a | #5b4d0b | подсветка цитаты в источнике |

Тема: системная по умолчанию, переопределяется `data-theme` на `<html>`. Шрифты: Inter (текст), JetBrains Mono (служебное: номера слайдов, токены, трасса запроса).

## Правила

- Карточка: `bg-panel border border-line rounded-[10px] p-4`; кнопка: `bg-acc text-white rounded-lg px-3.5 py-2.5 font-semibold`.
- Заголовок секции: 11 px, uppercase, `tracking-wide`, `text-mute`.
- Статус документа — пилюля: `agreed` ok, `refereed` warn, `review`/`failed` bad, `human` acc.
- Чат — три колонки `240px | 1fr | 400px`; источник показывает единицу ±1, текущая с подсветкой `hl`.
- До 768 px колонки становятся вкладками «Фильтры / Ответ / Источник», доска — две колонки KPI и блоки на всю ширину.
- Состояния: загрузка — скелетон из `sub`; пусто — текст + действие; ошибка — `bad` + «Повторить».
