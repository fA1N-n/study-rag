# Ядро загрузки датасета — критерии (TDD)

Модуль `src/lib/ingest/`. Чистые функции без сети и БД: на входе байты файлов, на выходе нормализованные документы. Сохранение в Storage и БД — в маршруте `/api/datasets/[id]/ingest`.

Нормализованный документ: `{ filename, sha256, units[], markdown, preview, piiFlag, meta }`, где `units` — единицы «Страница N / Слайд N / Раздел: …» (тип `Unit` из `src/lib/labeling/units.ts`), `markdown` — тот же текст в формате `docs/data-collection.md` (заголовки `## Страница N`), `preview` — начало документа для агентов после маскирования ПДн.

## Распаковка zip (`unzip.ts`)

- I1. zip с файлами в папках → список `{ name, data }` с полным путём внутри архива; папки (записи на `/`) не попадают.
- I2. Имя записи без UTF-8-флага в CP866 (архиватор Windows) → читается по-русски («Лекция 1.md»); имя с UTF-8-флагом → как есть; имя без флага, но валидное UTF-8 → как UTF-8.
- I3. Служебное (`__MACOSX/…`, `.DS_Store`, `Thumbs.db`, файлы на `._` и `~$`) пропускается без ошибки.
- I4. Не zip или битый zip → ошибка с понятным текстом, а не падение процесса.

## Извлечение текста (`extract.ts`)

- I5. `.md` с заголовками `## Страница/Слайд/Раздел` → единицы как у `parseDocument`; frontmatter → `meta`.
- I6. `.md` / `.txt` без таких заголовков → одна единица «Раздел: <имя файла без расширения>» со всем текстом; пустой файл → ошибка «пустой документ».
- I7. `.pdf` → по единице «Страница N» на каждую страницу с текстом, N — номер страницы в файле; PDF без текстового слоя (все страницы пустые) → ошибка «нет текстового слоя».
- I8. `.docx` → разделы по заголовкам 1–2 уровня («Раздел: <заголовок>»); текст до первого заголовка — «Раздел: Вступление»; без заголовков — одна единица «Раздел: <имя файла>»; заголовок 3+ уровня раздел не режет; стиль заголовка узнаётся по имени («heading 1»), а не по id (русский Word пишет id «1»).
- I9. Неподдерживаемое расширение (`.pptx`, `.png`, `.exe`, …) → пропуск с причиной «формат не поддерживается»; расширение без учёта регистра (`.PDF`).
- I10. Текст в UTF-8 с BOM и с CRLF → без BOM, переводы строк `\n`; `.txt` в Windows-1251 (невалидный UTF-8) → читается по-русски.

## Документ (`index.ts`, `ingestFiles`)

- I11. `sha256` — от байтов исходного файла (64 hex); одинаковые файлы под разными именами в одной загрузке → второй пропущен как «дубль»; файл, чей sha256 уже есть в датасете (`existing`) → пропущен как «дубль».
- I12. zip внутри списка файлов разворачивается; zip внутри zip не разворачивается (пропуск «вложенный архив»).
- I13. `filename`: из frontmatter `original_file`, если он есть (базовое имя без префикса-хэша `0123456789abcdef_`), иначе базовое имя файла; кракозябры CP866-как-CP437 чинятся (`fixMojibake`).
- I14. `markdown` при повторном разборе `parseDocument` даёт те же единицы (вид, номер, подпись, текст); строка вида `## Слайд 9` внутри текста не создаёт новую единицу (понижается до `###`).
- I15. Ошибка одного файла не роняет загрузку: файл уходит в `skipped` с причиной, остальные обрабатываются.
- I16. Больше `maxFiles` документов → лишние пропущены с причиной «лимит» (для демо — 30, задаёт маршрут); дубли и ошибки место в лимите не занимают; порядок обработки — по имени, детерминированный.

## ПДн (`src/lib/labeling/pii.ts`)

- I17. `preview`: не длиннее `max`; табы и пустые строки сжаты до нарезки; `<br>` → пробел; ПДн замаскированы ядром `maskPii` с `keepNames` (преподаватели).
- I18. Дополнительно маскируются: ФИО с отчеством в любом порядке («Петрова Анна Ивановна», «Иван Петрович Сидоров»), ФИО КАПСОМ с отчеством, номера из 9+ цифр подряд (паспорт, билет); ORCID, ISBN, даты, номера групп (4 цифры) — не трогаются; ФИО преподавателя из `keepNames` остаётся.
- I19. `maskFilename`: фамилия в имени файла маскируется («лаб3Иванов.docx», «Отчет_Петровой_ЛР2.pdf» → `[ФИО]`), слова-названия («Лекция», «Синхронизация», «Методичка») и фамилия преподавателя из `keepNames` — нет; расширение сохраняется.
- I20. `maskPath`: `C:\Users\<имя>\…` и `/home/<имя>/…` → `[пользователь]`, флаг ПДн это не ставит (домашняя папка — след сборщика, она есть у всех 572 документов); к частям пути применяется I19.
- I21. `piiFlag` = true, если в превью, имени или пути (включая путь внутри zip) что-то замаскировано; `filename` остаётся исходным, маскированное имя — `maskedFilename` (в БД пишется оно).
- I22. Текст единиц (а значит `markdown` в Storage и будущие чанки) тоже проходит `maskPii` с `keepNames`: проверяющий на демо не видит ФИО и телефонов в источнике.

## Пределы (известные)

- Фамилии в именах файлов ловятся по окончаниям русских фамилий (-ов/-ев/-ин/-ский/-енко/…); иностранные фамилии и латиница — нет. Ошибка в безопасную сторону: прилагательное на «-ский» в имени файла тоже замаскируется.
- Слово во множественном родительном с заглавной в имени файла («Теория Алгоритмов.pdf») замаскируется как фамилия; фамилия со строчной («лаб3_иванов») — нет.
- Лимит размера zip проверяется по размерам из заголовков записей; архив с ложными размерами (zip-бомба) этим не ловится.
- Кириллица в PDF в тестах не проверена (фикстура только ASCII).
- Скан-PDF без текстового слоя не распознаём (OCR вне рамок, spec §11).

## Критики (2026-11-08)

- Критик тестов (Opus): 12 недостающих тестов — все дописаны (маскирование до нарезки, путь внутри zip, docx внутри zip, `.ZIP`, обратные слэши, лимит и дубли, BOM в .txt, стиль заголовка по имени, Heading3, битый docx). Решения по ходу: docx без заголовков → «Раздел: <имя>», строка `## Слайд N` в тексте понижается до `###`, дубль место в лимите не занимает, добавлен I22.
- Финальный критик (Opus, прогон на всех 572 реальных документах): 16 дефектов, тесты D1–D15 в `src/lib/ingest/final-critic.test.ts`. Исправлено: подписи единиц маскируются; маршрут передаёт преподавателей из правил (`keepNames`); кракозябры чинятся по словам; «9+ цифр» маскируются только после слова-маркера (паспорт, билет, СНИЛС…) — было 2 168 ложных замен в лабах по системам счисления; .txt не разбирает frontmatter; перенос строки в заголовке docx; CP866-имя, похожее на UTF-8; `fixMojibake` не трогает «Café»; битый байт не переводит файл в CP1251, а «�» в валидном UTF-8 — не повод (иначе документ из 8 слайдов становился 1); формат проверяется до лимита. В маршруте: try/finally (сырые загрузки удаляются, статус не зависает), ошибки Supabase не глотаются, лимиты демо 30 файлов / 30 МБ, осиротевший файл удаляется.
