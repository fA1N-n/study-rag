## 2. Поиск

Вопросы: `questions.csv` — 64, после чистки 62 (убраны вопрос со ссылкой на имя файла и дубль формулировки): 54 отвечаемых (у 53 ожидаемый документ найден в БД) и 8 «нет ответа». Попадание — ожидаемый документ среди первых 5 документов выдачи (hit@5) и обратный ранг до 10 (MRR@10). Метрика строгая: если на вопрос отвечает и другой документ, это промах.

| Режим | n | hit@5 | MRR@10 |
|---|---|---|---|
| Без меток: гибрид вектор + FTS → RRF, без фильтров | 53 | 73,6 % | 0,544 |
| С метками: тот же гибрид + фильтр по предмету | 53 | **83,0 %** | 0,630 |
| Подвыборка 20: с метками, без rerank | 20 | 80,0 % | 0,614 |
| Подвыборка 20: с метками + rerank LLM (порог 4/10) | 20 | 70,0 % | 0,512 |

- **Цель hit@5 ≥ 0,8 достигнута с верным фильтром по предмету** (83,0 % = 44 из 53, интервал Уилсона 71–91 %, то есть в пределах погрешности). Фильтр добавляет +9,4 п. п. hit@5 (5 вопросов) и +0,086 MRR — польза разметки для поиска при верно выбранном предмете.
- **Фильтр здесь — оракул:** предмет берётся из колонки `subject` вопроса в `questions.csv` (`scripts/eval/search-eval.ts`), запрос не переписывается, автофильтр не угадывается. Весь путь `/api/ask` (переписывание + автофильтр + rerank) на всех вопросах не измерен; ближайшая цифра — 70 % на подвыборке 20 (первые 20 вопросов, не случайные).
- **Rerank бесплатной моделью ухудшил выдачу** на подвыборке: −10 п. п. hit@5. Ожидаемый документ выпал из выдачи после rerank в 6 из 20 вопросов; в 2 из них вся выдача отсеялась порогом (ложный отказ).
- **Отказы:** на 8 вопросах «нет ответа» (поиск без фильтра) выдача после порога rerank пуста в 6 (75 %); на отвечаемых — в 2 из 20 (10 %, ложный отказ). Отказ = пустая выдача после rerank, ответ модели не оценивался.
- Вывод: rerank нужен для отказов (без него отказа нет вовсе), но слабая бесплатная модель режет хорошие фрагменты. Варианты на будущее — порог 3/10 вместо 4/10, rerank только для порога отказа без пересортировки, модель сильнее.

Заголовок чанка (метки) входит в эмбеддинг и FTS в обоих режимах — «без меток» здесь значит «без фильтров по меткам»; отдельный индекс без заголовков не строили (лимит бесплатных эмбеддингов). Rerank — только на 20 вопросах (лимит 50 запросов в день). Вопросы `questions.csv` сгенерированы моделью по документам, настоящих вопросов от людей нет — метрики могут быть завышены.
