# Требования к проекту — чеклист

Сдаём по двум курсам: «Большие данные» (КАИ, проектная работа, отчёт .docx по образцу FlowDesk / SkillPath AI) и OTUS «Разработка веб-приложения с AI-агентами». Требования общие.

Отмечаем по мере выполнения. Где закрыто — ссылка на файл/коммит/скриншот.

## Функциональность
- [ ] ≥3 экранов (v2: вход, датасеты, загрузка, правила, разметка, проверка, документы, чат, история; прототип v1 на моках есть)
- [ ] Адаптивная вёрстка (мобильный + десктоп)
- [ ] Формы с валидацией (zod на клиенте и сервере + CHECK в БД)
- [ ] Состояния загрузки, ошибок, пустые состояния
- [ ] Postgres, ≥3 связанных таблиц (datasets → documents → labels / chunks, rulesets, label_jobs → batches, questions)
- [ ] CRUD в UI: датасеты (создать / переименовать / удалить)
- [ ] CRUD в UI: документы (загрузить / править метки / удалить), правила (сгенерировать / править / утвердить)
- [ ] Аутентификация (Supabase Auth, регистрация закрыта, кнопка «Войти как проверяющий» с лимитами), RLS
- [ ] Доп. функция 1: внешний API (LLM DeepSeek через OpenRouter, эмбеддинги, reranker)
- [ ] Доп. функция 2: загрузка файлов (.md в Supabase Storage → индексация)
- [ ] Доп. функция 3: поиск и фильтры (гибридный поиск, фильтры предмет/семестр/преподаватель/тип)

## Разметка (v2)
- [ ] Агент-архитектор + критик генерируют схему и правила, человек утверждает
- [ ] Батчи, разметчики A и B, валидатор, арбитр, очередь проверки
- [ ] Доска прогресса вживую, токены и стоимость
- [ ] Маскирование ПДн перед отправкой в LLM
- [ ] Метрики: точность на золотом наборе, каппа A/B, «один разметчик» против «двое + арбитр»

## Качество RAG (не упрощать)
- [ ] Контекст в чанке: предмет · семестр · документ · слайд/страница
- [ ] Гибрид FTS (russian) + вектор + RRF
- [ ] Reranker
- [ ] Переписывание запроса + автофильтры
- [ ] Соседние слайды ±1
- [ ] Честный отказ, если ответа нет; сноски на документ и слайд
- [ ] Eval: hit@5 ≥ 0.8, таблица «до/после» и «без меток / с метками» в docs/eval.md
- [ ] Фидбек 👍/👎, история вопросов
- [ ] Стриминг ответа
- [ ] Дедуп документов (sha256)
